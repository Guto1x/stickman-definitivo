# How to use this system

Open this folder in Claude Code and just ask. Claude follows `CLAUDE.md`. These are the things you can say.

**New machine?** Follow `docs/SETUP.md` first (clone, `npm ci`, Python venv, FFmpeg, `.env` key).

## One command: topic to finished video
> /stickman What If You Could Breathe Underwater

Claude writes, voices, renders and reviews the whole episode with your saved hero, then generates 3 thumbnails. It stops once, before spending ElevenLabs credits, to show you the script score and the credit estimate.

## Make a new episode
> "Give me 3 new What If ideas."

Claude runs the idea engine (`docs/story/IDEA_ENGINE.md`):
- it generates and scores candidates;
- it checks them against competitors' titles;
- it pitches the top 3 with titles and thumbnail concepts.

> "Make the one about ___, 10 minutes."

Claude then works through five steps, stopping at each checkpoint for you:
1. **Script.** Claude writes it with `docs/story/STORY_BLUEPRINT.md` and shows it to you with a score. Ask for changes until you're happy.
2. **Preview.** Claude turns the script into a shot list and renders a quick preview with estimated timing, before any voice credits are spent.
3. **Voice.** Claude voices it with ElevenLabs (Matheus, always animated, eleven_v4; about 0.45 credits per character), aligns every cut to the words, and builds music and sound effects.
4. **Render.** Claude renders `final/<Episode title>.mp4` and reviews every shot before handing it over. Older cuts move to `final/archive/`.
5. **Thumbnail.** Claude makes 2–3 thumbnail options; pick one.

## Make a short scene or test shot
> "Make a 6-second shot of the hero ___."

Claude builds it like `src/demo/PillSprint.tsx`, with Python sound effects, and delivers `final/<name>.mp4`.

## Change things
- **Character outfits:** `src/cast.ts`. The hero wears the gray quarter-zip jacket; there are also bestie, sister, mom, dad, teacher, coach, rival, scientist and kid. Ask "give the hero a cap", "add a villain in a black suit", and so on.
- **Places:** ask "add a hospital set" or "make the classroom bigger". Sets live in `src/sets/`.
- **Explainer cards:** stat, compare, distance, speed, clock, chain, rules, icon and title. Ask for new ones the same way.
- **Music:** generated by mood (curious, wonder, tension, action, sad). To use your own track, put it in `public/music/` and say "use my_track.mp3 for the intro".
- **Voice:** set in `docs/pipeline/EPISODE.md` (Voice section). Ask Claude to audition others.

## Preview yourself
Run `npm run studio`, then pick **Episode** (props `{"slug":"<slug>"}`), **PillSprint**, **Thumbnail**, **CharacterLab**, **SetLab** or **CardLab**.

## Where things are
| Path | What |
|---|---|
| `final/` | All finished videos in one folder, named by title; `thumbnails/` and `archive/` (older cuts, tests) inside. See `final/README.md` |
| `public/episodes/<slug>/` | Each episode: `episode.json` (the shot list), voice, timing, mix |
| `docs/STYLE.md` | The visual style bible |
| `docs/story/` | Storytelling blueprint and idea engine |
| `docs/research/` | The channel analysis this is all based on |
